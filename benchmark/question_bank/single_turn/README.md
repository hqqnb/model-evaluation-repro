# 单轮题目材料

这里保存统一题库中不需要工具执行闭环的 20 道题，覆盖推理、Coding 和多模态三个部分。它们与 `../agent/` 中的 Agent 题属于同一套题库，只是执行方式不同。

## 目录

- `dataset/prompts.json`：实际下发给模型的题目，不包含内部答案。
- `rubrics/rubrics.json`：题目对应的评分信息和人工评审重点，不得下发给被测模型。
- `assets/`：题目中引用的固定图片素材。
- `outputs/`：模型原始输出的记录说明；正式运行结果应按 run ID 单独归档。
- `source_material/`：题面、内部答案、Coding 检查脚本和来源材料。

## 评测方式

1. 评测程序从 `dataset/prompts.json` 读取题目。
2. 每次请求只发送一道题及其附件，避免不同题目之间相互影响。
3. 原始请求、响应、最终回答、耗时、Token 和错误信息进入结果归档。
4. 推理题和多模态题按评分规则复核；Coding 题在人工检查之外运行黑盒或项目级测试。
5. 运行 `python3 scripts/validate_dataset.py` 检查题目、评分和素材引用是否一致。

内部答案、评分规则和参考实现只用于评测，不会作为模型输入。
