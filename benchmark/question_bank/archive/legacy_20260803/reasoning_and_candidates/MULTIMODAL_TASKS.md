# 多模态理解能力正式候选题库

日期：2026-08-03

本题库根据此前实际使用过的三类视觉题型重建，另增加一道同源的多图规律题。原始 KU 图片本次因接口限流未能下载，因此 M01-M03 的历史来源与正式运行资产分开记录；正式资产均可复现、可核对，不把合成图冒充历史原图。

## 1. 统一规则

多模态理解不是图片描述，也不是前端审美评分。模型需要完成：

1. 视觉事实提取；
2. 视觉关系或规律理解；
3. 图文对齐；
4. 证据约束下的结论。

每题 100 分，结果只展示多模态总分、题目级得分、结构化答案和失败证据，不对外拆分子能力分。

通用严重失败：

- 把图片中不存在的文字、对象、数字或状态当成事实；
- 得到正确选项但给出与图片不符的规律；
- 只输出长篇自然语言，没有题面要求的结论字段；
- 把推测写成图片直接支持的事实。

每次运行保存原图、题面版本、模型原始回答、解析结果、标准答案、逐项得分和证据卡。

## M01 星形隐藏问句

### 来源与资产

- 来源：此前实际使用过的“星形排列、杂乱字母中隐藏问句”题型。
- 正式资产：`benchmark/assets/multimodal/m01-star-hidden-question.svg`
- 原始资产：若后续从 KU 恢复，存放在 `benchmark/assets/multimodal/source/`，不覆盖正式资产。

### 主要区分点

复杂布局中的视觉文字提取、路径追踪、问句解析和精确计数。只会 OCR 或只看见星形但不能沿路径读完问句的模型不能得满分。

### 给模型的题面

> 图片中有大量干扰字母，并有一条由五个顶点组成的星形路径。请沿星形路径读取隐藏的英文问题，再回答该问题。
>
> 输出严格遵循：
>
> `{"hidden_question":"完整英文问句","answer":整数,"evidence":"说明读取路径和计数口径"}`

### 标准答案

```json
{
  "hidden_question": "HOW MANY WORDS CONTAIN THE LETTER R",
  "answer": 2,
  "evidence": "沿五角星路径读取；WORDS 和 LETTER 含有字母 R。"
}
```

### 计分项

| ID | 可验证要求 | 分值 |
|---|---|---:|
| M01-1 | 识别星形路径和正确读取方向 | 20 |
| M01-2 | 完整恢复隐藏问句，允许大小写差异 | 25 |
| M01-3 | 正确解析“单词”和“包含字母 R”的口径 | 20 |
| M01-4 | 最终计数为 2 | 25 |
| M01-5 | JSON 字段完整，证据与图片一致 | 10 |

### 严重失败规则

- 只转录零散字母，没有恢复问句：M01-2 不得分。
- 统计干扰字母而不是问句中的单词：M01-3 和 M01-4 不得分。
- 只写出答案 2，但没有任何可核对的问句或证据：总分上限 35 分。

### 变体与防猜

- 替换问句模板和目标字母；
- 改变干扰字母密度和颜色；
- 旋转星形整体，但不改变沿路径读取顺序；
- 添加可读但不属于路径的短词。

搜索到原题答案但不能恢复图片中的问句，M01-1 和 M01-2 不得分。

### 人类证据卡

显示星形轮廓、读取顺序、隐藏文本、逐词标记和计数结果。审核者无需理解 OCR 技术即可核对。

## M02 图形规律推理

### 来源与资产

- 来源：此前实际使用过的“四个选项中选择最合适图形”题型。
- 正式资产：`benchmark/assets/multimodal/m02-pattern-matrix.svg`
- 历史结果曾出现：正确识别对称轴旋转规律的模型通过，无法看图或误读矩阵结构的模型失败。

### 主要区分点

从图片中同时提取方向和数量两个变化维度，并将规律应用到缺失格。不是只看选项形状相似度。

### 给模型的题面

> 请观察左侧 3×3 图形矩阵和右侧四个选项，选择最适合填入问号处的选项。
>
> 至少说明两个可核对的规律，并指出为什么至少两个其他选项不符合。
>
> 输出严格遵循：
>
> `{"option":"A/B/C/D","rules":["规律"],"evidence":["图片证据"],"rejected":{"A":"原因","B":"原因","C":"原因","D":"原因"}}`
>
> 不要把正确选项写进 `rejected`。

### 标准答案

```json
{
  "option": "C",
  "rules": [
    "箭头方向沿列从上到下每格顺时针旋转 90 度",
    "圆点数量由行列共同决定，每向下或向右移动一格增加一个，因此缺失格应有 5 个圆点"
  ],
  "evidence": [
    "第三行前两格方向为向下、向左，缺失格应继续旋转到向上",
    "第三行前两格分别有 3、4 个圆点，缺失格应有 5 个圆点"
  ],
  "rejected": {
    "A": "方向正确但只有 2 个圆点",
    "B": "圆点数量不符合第三行，方向也不符合缺失格",
    "D": "圆点数量正确但方向应为向上而不是向左"
  }
}
```

### 计分项

| ID | 可验证要求 | 分值 |
|---|---|---:|
| M02-1 | 识别矩阵结构、箭头方向和圆点数量 | 20 |
| M02-2 | 识别方向变化规律 | 20 |
| M02-3 | 识别数量变化规律 | 20 |
| M02-4 | 选择 C | 25 |
| M02-5 | 至少排除两个错误选项且理由对应图片 | 10 |
| M02-6 | JSON 字段完整 | 5 |

### 严重失败规则

- 不能识别 3×3 矩阵结构：M02-1 不得分。
- 通过猜选项得到 C，但两个规律均与图片不符：M02-2、M02-3 和 M02-5 不得分。
- 只给出选项字母，没有规律或证据：总分上限 25 分。

### 变体与防猜

- 随机旋转整张矩阵；
- 改变箭头初始方向；
- 将圆点换成短线或小方块；
- 让错误选项分别只错一个维度。

模型如果通过联网找到原题答案，但没有给出图片中的两个规律，最多得 50 分。

### 人类证据卡

在每个格子上标注箭头方向和点数，单独显示缺失格的两个约束以及四个选项各自违反的维度。

## M03 图片爆火原因识别

### 来源与资产

- 来源：此前实际使用过的“这张图片很火，请解释一下其原因”题型。
- 正式资产：`benchmark/assets/multimodal/m03-viral-contrast-card.svg`
- 说明：该资产是同类、可版本化的对比型梗图，不冒充原始 KU 图片。原始图片恢复后作为历史对照，不改变正式答案协议。

### 主要区分点

识别图片内容，并区分：

- 图片直接可见的证据；
- 可以合理解释传播的机制；
- 必须联网才能确认的出处和传播事实；
- 模型自己的推测。

这道题不把“写得丰富”当成高分。没有证据边界的流畅回答不能满分。

### 给模型的题面

> 请分析图片为什么可能被大量转发。只依据图片能够确认的内容，不要假设它对应某个真实人物或具体历史事件。
>
> 请分别回答：
>
> 1. 图片中直接可见的元素；
> 2. 这种图片可传播的机制；
> 3. 哪些内容需要联网或原始出处才能确认；
> 4. 哪些判断只是推测。
>
> 输出严格遵循：
>
> `{"visible_content":["事实"],"spread_mechanisms":[{"claim":"机制","evidence_type":"image|search|inference"}],"external_facts":[{"claim":"事实","source":"来源或未确认"}],"uncertainties":["不确定项"]}`

### 标准答案

```json
{
  "visible_content": [
    "图片采用左右对比构图",
    "两侧表现相同计划下的不同执行状态",
    "左侧标题为 CALM，右侧标题为 RUSH",
    "画面有同一类人物的稳定姿态与慌乱姿态对照"
  ],
  "spread_mechanisms": [
    {"claim": "强对比使含义可以快速被理解", "evidence_type": "image"},
    {"claim": "同一模板可以替换不同人物、场景和文字", "evidence_type": "inference"},
    {"claim": "观众容易把自己的计划落差投射到图片上", "evidence_type": "inference"},
    {"claim": "短标题和左右结构适合截图、转发和二次配文", "evidence_type": "image"}
  ],
  "external_facts": [
    {"claim": "该图片的真实传播量、最早出处或具体平台热度", "source": "未确认"}
  ],
  "uncertainties": [
    "无法仅凭图片确认它是否真的爆火",
    "无法仅凭图片确认具体作者、发布时间或传播平台"
  ]
}
```

### 计分项

| ID | 可验证要求 | 分值 |
|---|---|---:|
| M03-1 | 正确识别左右对比、标题和人物状态 | 25 |
| M03-2 | 至少给出两个由图片支持的传播机制 | 25 |
| M03-3 | 正确标注哪些事实需要外部来源确认 | 20 |
| M03-4 | 至少给出一个合理推测，并标为 inference | 10 |
| M03-5 | 明确指出无法仅凭图片确认真实热度和出处 | 10 |
| M03-6 | JSON 字段、证据类型和来源字段完整 | 10 |

### 严重失败规则

- 把图片识别成图片中没有明确出现的具体公众人物或真实事件：M03-3 和 M03-5 不得分。
- 将作者、发布时间、平台热度等未提供事实写成确定结论：相关证据项不得分。
- 只写一篇流畅的“爆火原因”文章，没有字段和证据类型：总分上限 40 分。

### 变体与防猜

- 替换左右标题和人物动作；
- 保持同一传播机制但更换画面主题；
- 加入一个容易诱发具体人物联想、但图片没有提供身份信息的视觉元素；
- 设置一条看似具体但实际未提供来源的传播数据。

### 人类证据卡

分为三栏：

1. 图片内可见事实；
2. 可接受的传播机制；
3. 应标记为检索事实或推测的内容。

## M04 多图规律与异常定位

### 来源与资产

- 来源：在既有图形规律题基础上扩展的多图版本。
- 正式资产：`benchmark/assets/multimodal/m04-multi-panel-anomaly.svg`

### 主要区分点

跨图片追踪同一对象，识别连续变换，并定位只发生在一个局部的异常。该题避免单张图形题可能出现的“猜中选项”。

### 给模型的题面

> 请观察 P1 至 P5 五个连续面板：
>
> 1. 说明三角形方向如何变化；
> 2. 说明右上角圆形标记如何变化；
> 3. 找出唯一不符合规律的面板和局部区域；
> 4. 给出该区域按规律应有的状态。
>
> 输出严格遵循：
>
> `{"pattern":["规律"],"anomaly_panel":整数,"anomaly_region":"区域","observed":"状态","expected":"状态","evidence":"图片证据"}`

### 标准答案

```json
{
  "pattern": [
    "箭头方向沿面板顺序顺时针旋转 90 度",
    "右上角圆形标记在正常面板中交替呈现 filled、outline、filled、outline、filled"
  ],
  "anomaly_panel": 4,
  "anomaly_region": "右上角圆形标记",
  "observed": "filled",
  "expected": "outline",
  "evidence": "P1、P2、P3、P5的同一位置呈现 filled、outline、filled、filled，P4的 filled 状态破坏交替规律。"
}
```

### 计分项

| ID | 可验证要求 | 分值 |
|---|---|---:|
| M04-1 | 正确对应五个面板中的箭头和圆形标记 | 20 |
| M04-2 | 箭头方向变化规律正确 | 20 |
| M04-3 | 圆形标记状态规律正确 | 20 |
| M04-4 | 定位 P4 的右上角标记异常 | 25 |
| M04-5 | 正确给出 observed=filled、expected=outline | 10 |
| M04-6 | JSON 字段和证据完整 | 5 |

### 严重失败规则

- 只指出 P4 异常但没有说明两个规律：总分上限 50 分。
- 把箭头或圆形标记在不同面板中误认成不同对象：对应规律项不得分。
- 只根据颜色而不检查填充状态：M04-3 和 M04-5 不得分。

### 变体与防猜

- 改变起始方向和标记位置；
- 将异常放到中间或末尾面板；
- 用三种状态循环替换二状态循环；
- 让箭头规律和标记规律互相独立，防止只依赖一个显眼特征。

### 人类证据卡

并排展示五个面板，用同色框连接相同位置的对象，再用红框标出 P4 的圆形标记，旁边列出 observed 和 expected。

## 2. 正式入库门槛

当前四题均为正式候选题，不直接代表最终公开排名。正式入库前必须：

1. 为每题制作至少 8 组等价难度变体；
2. 为每个变体保存唯一答案和版本号；
3. 用至少 6 个不同水平模型预跑；
4. 删除几乎全部满分、几乎全部零分或主要由图片清晰度决定的变体；
5. 抽查每题一个满分答案和两个典型错误答案；
6. 确认非专业审核者可以在 3 分钟内通过证据卡核对结果。
