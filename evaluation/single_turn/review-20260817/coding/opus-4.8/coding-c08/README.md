# Tactical Strike — 浏览器战术射击（CS 风格爆破模式）

纯前端、单机、可玩的第一人称战术射击游戏，使用 Three.js（已本地内置于 `vendor/`，无需联网）。
包含 3 张地图（含高度还原的 **Dust II** 战术结构）、完整爆破模式、经济系统、购买菜单、Bot AI 与四档难度。

## 运行方式

需要用静态服务器打开（ES 模块 + 指针锁定不能用 `file://`）：

```bash
cd cs2-tactical
python3 -m http.server 8177
# 浏览器打开 http://localhost:8177
```

点击画面锁定鼠标；`Esc` 解锁 / 暂停。

## 操作

- 移动：`W A S D`　静步：`Shift`　下蹲：`Ctrl`　跳跃：`Space`
- 开火：鼠标左键　开镜：鼠标右键　换弹：`R`
- 切枪：`1` 主武器 / `2` 手枪 / `3` 刀 / `4` 投掷物（`4` 再按循环）；滚轮切换
- 购买：`B`（数字键或点击快速购买）　下包/拆包：靠近并按住 `E`
- 记分板：`Tab`　暂停：`Esc`

## 特性

- **爆破模式**：下包(3.2s)/拆包(5s 有拆弹器/10s 无)/40s 炸弹倒计时/爆炸/胜负判定/回合倒计时。
- **经济系统**：击杀奖励、胜负奖励、连败补偿、下包/拆包奖励、上限 $16000；存活可保枪。
- **武器**：手枪(Glock/USP/P250/Five-SeveN/沙鹰)、冲锋枪(MP9/MP5/P90)、步枪(Galil/FAMAS/AK-47/M4A4/AUG)、狙击(SSG08/AWP)、霰弹(Nova/XM1014)；后坐力弹道、散布、开镜、换弹、切枪、枪口火焰、弹道曳光与命中特效。
- **投掷物**：高爆手雷（范围伤害）、闪光弹（致盲玩家/Bot）、烟雾弹（遮挡视线与 AI 视野）、燃烧瓶（区域灼烧）；真实抛物线与墙面反弹。
- **命中系统**：爆头倍率、护甲/头盔减伤、生命值、死亡、观战。
- **Bot AI**：A* 路径寻路 + 状态机（进攻/防守/占点/下包/拆包/补枪/投雷/绕点），四档难度影响反应速度、瞄准精度、交战距离、投掷物使用与爆头率。
- **UI**：准星、雷达小地图、血量/护甲/弹药、回合时间、比分、击杀提示、记分板、购买菜单、主菜单/暂停/结算。
- **音效**：合成枪声（分武器）、脚步、换弹、爆炸、闪光、下包/拆包/回合提示音（Web Audio，带方位与距离衰减）。

## 地图

- **Dust II**：还原 T/CT 出生点、A/B 包点、中路、中门、A 大(长通)、长门/双门、A 小/楼梯(架高走道)、A 坑、Xbox、B 洞(隧道)、B 门、B 平台、警家(CT 家)、A 斜坡、箱体掩体、狙击对枪长线，及其连接关系与攻防/回防/夹击路线。
- **炼油厂 Refinery**（原创）：中央仓库 + 架高走道，东西罐区双包点，节奏偏近距离与垂直交战。
- **运河 Canals**（原创）：中央大桥长狙击线，两翼近距离绕后，A 广场 / B 货场。

## 代码结构（`js/`）

`main.js` 引导与主循环 · `scene.js` 渲染/相机/光照 · `input.js` 输入 · `audio.js` 音效 ·
`textures.js` 程序化贴图 · `math.js` 数学 · `weapons_data.js` 武器数据 · `weapon_view.js` 视角武器/弹道 ·
`grenades.js` 投掷物 · `player.js` 玩家控制 · `bot.js` Bot AI · `nav.js` 寻路 · `map_builder.js` 世界/碰撞 ·
`maps.js` 地图注册(含两张原创) · `dust2.js` Dust2 布局 · `economy.js` 经济 · `game.js` 对局管理 · `ui.js` HUD/菜单。
