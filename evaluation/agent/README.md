## 脱敏边界

归档前已检查并处理 API Key、Bearer Token 和其他凭据。不要把本地 `.env`、Cookie、浏览器登录态、未脱敏业务数据或原始运行目录复制到这里。

## 复核顺序

1. 先看正式总分文件，确认项目级排名口径。
2. 再看最终批次摘要，确认本轮运行是否有技术失败。
3. 最后按需要打开交互证据和结构化复核材料。
